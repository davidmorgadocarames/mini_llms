Un mini-LLM decoder-only (RoPE, RMSNorm, SwiGLU, Grouped Query Attention) entrenado desde cero sobre WikiText-103. Esta página es una demo estática: reproduce con una animación de escritura los textos reales que generó el modelo entrenado — sin backend, sin GPU, sin instalar nada. Para generación libre con cualquier prompt, corre python coconut.py desde el repositorio.

coconut — bash
>
Arquitectura y entrenamiento explicados en el README del repo. Este mismo proyecto incluye una Fase B que reproduce y extiende un paper de AAAI 2026 sobre por qué los Transformers fallan en razonamiento recursivo profundo.
